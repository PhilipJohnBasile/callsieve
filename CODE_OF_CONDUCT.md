# Code of Conduct

CallSieve is a technical project for local-first codebase intelligence. Project spaces should stay useful, direct, and safe for people doing engineering work.

## Expected Behavior

- Be respectful and constructive.
- Keep discussion focused on the code, docs, product scope, and evidence.
- Challenge ideas with specific technical reasoning.
- Respect privacy, proprietary code, and confidential customer or pilot data.
- Use inclusive language and avoid personal attacks.
- Help maintain a practical, local-first open source project.

## Unacceptable Behavior

- Harassment, threats, insults, slurs, or sustained personal attacks.
- Publishing private information without clear permission.
- Sharing proprietary code, private traces, security details, or customer data in public channels.
- Repeated off-topic disruption after maintainers ask for the thread to return to scope.
- Trolling, spam, or behavior that makes collaboration unsafe or unproductive.

## Scope

This code of conduct applies in project spaces, including GitHub issues, pull requests, discussions, releases, community chats, and any project-related events or direct maintainer interactions.

## Reporting

Report conduct concerns to the maintainers through GitHub. If a report involves safety, privacy, security, or confidential data, avoid posting details publicly. Contact a maintainer privately or ask for a private reporting channel.

Maintainers will review reports as promptly as practical, preserve confidentiality where possible, and take action proportionate to the situation. Actions may include clarification, comment moderation, temporary limits, or removal from project spaces.

## Maintainer Standards

Maintainers are expected to apply this code of conduct fairly and consistently. Maintainers should make moderation decisions in the interest of a focused, respectful, technically rigorous project.
